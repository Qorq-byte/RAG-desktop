# Code of Conduct

## Our standard

We want RAGDB to be a welcoming project for people with different backgrounds and levels of experience. Participate with respect, assume good faith, and focus feedback on the work.

Unacceptable behavior includes harassment, discrimination, threats, personal attacks, sexualized attention, deliberate disruption, and publishing private information without permission.

## Applying the standard

Project maintainers may edit or remove comments, close discussions, or restrict participation when behavior violates this Code of Conduct. They will explain decisions when practical and will handle reports respectfully.

## Reporting

Report conduct concerns privately to the maintainers through the contact method listed in the repository profile. Do not include secrets or private knowledge-base content. For security vulnerabilities, follow [SECURITY.md](SECURITY.md).

This Code of Conduct is adapted from the Contributor Covenant, version 2.1.
